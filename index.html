Antes de tudo

Quando o operador era o sistema operacional

Na primeira geração de computadores, nos anos 1950, o computador ocupava uma sala inteira, com quilômetros de fios. Não existia sistema operacional: o operador tinha que ligar e desligar chaves, trocar painéis e esperar as luzes de aviso para o computador funcionar.

Com o tempo, essas tarefas repetitivas passaram a ser feitas por software, e esse software virou o que hoje chamamos de sistema operacional: o programa que gerencia a máquina para que as pessoas e os outros programas não precisem fazer isso à mão.

  1. Anos 1950 Tudo manual Chaves, painéis e luzes. Um programa por vez, controlado pelo operador.
  2. Anos 1960 Automação Programas passam a fazer as tarefas em sequência sozinhos e a dividir o computador entre várias pessoas.
  3. 1969 Nasce o UNIX Um sistema simples, que podia ser levado para outros computadores. Vira a raiz de quase todos os SOs modernos.
  4. 1981 Chega o MS-DOS O sistema dos computadores pessoais (PCs) da IBM, de onde nasce a família Windows.

Conceitos-chave

Kernel × Sistema Operacional

A árvore mistura dois tipos de “parentes”. Entender a diferença é o que faz a árvore fazer sentido.

Kernel

É o núcleo, a parte que conversa direto com o hardware (as peças físicas do computador). Decide qual programa usa o processador em cada momento, organiza a memória e controla os dispositivos (disco, teclado, rede). O usuário quase nunca o vê.

Sistema Operacional

É o kernel mais tudo o que vem em volta: interface, programas, utilitários e configurações. É o que a gente instala e usa no dia a dia: Windows, macOS, Ubuntu, Android…

Uma analogia

Pense num carro: o kernel é o motor e o SO é o carro inteiro. Vários carros diferentes podem usar o mesmo motor. É por isso que Android e Ubuntu, tão diferentes, compartilham o kernel Linux.

Os três tipos de kernel

Tudo junto

Monolítico

Todo o núcleo (drivers, sistema de arquivos, rede) roda como um único programa com acesso total à máquina. É rápido, mas uma peça com defeito pode derrubar o sistema inteiro.

Exemplos: UNIX, BSD, Linux, MS-DOS, Windows 9.x

O mínimo no núcleo

Microkernel

O núcleo faz só o essencial (memória, programas em execução e comunicação entre eles). O resto roda como programas separados, então uma falha num deles não derruba tudo. Mas eles precisam trocar mensagens o tempo todo, o que deixa o sistema mais lento.

Exemplo: Mach

Meio-termo

Híbrido (misto)

Começa com o desenho de um microkernel, mas coloca várias partes de volta dentro do núcleo para ganhar velocidade. Tenta juntar a organização de um com a rapidez do outro.

Exemplos: Windows NT (XP ao 11), XNU (macOS e iOS)

Como ler a ficha técnica

Ao clicar em um item da árvore, abre uma ficha com cinco características. Veja o que cada uma quer dizer:

Multiusuário

Várias pessoas usando o mesmo sistema ao mesmo tempo, cada uma na sua sessão, por exemplo conectadas pela rede. Ter várias contas no mesmo PC não basta: se só uma pessoa usa por vez, ele não é multiusuário.

Sim: UNIX, Linux, Windows Server · Não: MS-DOS, Windows 11

Multiprocessado

O sistema consegue dividir o trabalho entre vários processadores ou núcleos. O processador é o “cérebro” do computador; um núcleo é como um cérebro dentro dele. Mais núcleos, mais tarefas feitas ao mesmo tempo.

Sim: Linux, macOS, Windows XP ao 11 · Não: MS-DOS, Windows 95

Tipo de kernel

Como o núcleo é organizado: monolítico, microkernel ou híbrido (misto). Os três tipos estão explicados logo acima.

Sistema de arquivos

É o jeito de organizar e guardar os arquivos no disco, como o sistema de uma biblioteca para saber onde está cada livro. Define, por exemplo, o tamanho máximo de um arquivo e quem pode abri-lo.

Exemplos: FAT (MS-DOS), NTFS (Windows), ext4 (Linux), APFS (Apple)

Compartilhamento de arquivos

As formas de passar arquivos para outras pessoas e computadores: pastas compartilhadas na rede, envio sem fio entre aparelhos ou a nuvem (arquivos guardados em servidores na internet).

Exemplos: SMB (Windows), NFS (UNIX e Linux), AirDrop (Apple)

Pequeno glossário

Hardware
As peças físicas do computador: processador, memória, disco, teclado, tela.
Software
Os programas, ou seja, as instruções que dizem ao hardware o que fazer.
Processador e núcleo
O processador é o “cérebro” que faz as contas. Os processadores atuais têm vários núcleos, que trabalham ao mesmo tempo.
Driver
Programa que ensina o sistema a usar uma peça de hardware, como uma impressora ou uma placa de vídeo.
Linha de comando
Jeito de usar o computador digitando comandos numa tela de texto, sem janelas nem mouse.
Interface gráfica
Jeito de usar o computador com janelas, ícones e mouse ou toque.
Terminal
Tela e teclado usados para dar comandos a um computador, perto dele ou pela rede.
SSH
Forma segura de acessar outro computador pela rede e usar o terminal dele.
Rede local
Os computadores ligados entre si numa casa, escola ou escritório.
SMB e Samba
O SMB é a “língua” que o Windows usa para compartilhar pastas e impressoras na rede. O Samba é o programa que ensina essa língua ao Linux e a outros sistemas.
NFS
Forma de abrir uma pasta de outro computador como se ela estivesse no seu. Muito usado no UNIX e no Linux.
32 bits e 16 bits
Quanto maior o número de bits, mais memória o sistema consegue usar e mais rápido ele trabalha com números grandes.
Código aberto e software livre
Programas cujo código pode ser lido por qualquer pessoa. O software livre vai além: também pode ser alterado e distribuído.
Distribuição Linux
Um sistema completo montado em cima do kernel Linux, com programas, interface e instalador. Exemplos: Debian, Ubuntu e Linux Mint.
Nuvem
Arquivos e programas guardados em servidores na internet, que podem ser acessados de qualquer lugar.

Linhagem UNIX

Mach/Apple, BSD e Linux

Por que o XNU tem dois pais? O XNU combina a arquitetura do microkernel Mach com elementos do BSD: o Mach cuida da memória e dos processos, e o BSD traz rede, sistema de arquivos e as permissões no estilo UNIX.

As famílias

Quatro famílias, duas raízes

A família Microsoft descende do MS-DOS. As outras três (BSD, Apple e Linux) descendem do UNIX.

Raiz: MS-DOS

Microsoft

Do MS-DOS, usado digitando comandos, ao Windows 11. Primeiro veio o kernel 9.x, que ainda dependia do DOS (Windows 95 e 98). Depois, o kernel NT, mais estável e seguro, usado do XP em diante.

    Raiz: UNIX

    BSD

    O “UNIX de Berkeley”. Versão do UNIX feita numa universidade, que deu origem a sistemas livres como FreeBSD e OpenBSD e emprestou partes importantes para a Apple.

      Raiz: UNIX

      Apple

      O microkernel Mach somado ao BSD formou o XNU. Sobre ele está o Darwin, que por sua vez é a base do macOS e do iOS.

        Raiz: UNIX

        Linux

        Um kernel livre criado por Linus Torvalds em 1991. Sobre ele nasceram as “distribuições” (Debian, Ubuntu, Linux Mint) e até o Android.
